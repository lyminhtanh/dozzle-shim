What it is

Dozzle is a great browser UI for Docker container logs. But during local development most services log to plain files, not Docker. dozzle-shim bridges that gap: it serves Dozzle's unmodified UI and feeds it by tailing your log files directly, so you get the same clean interface — live tail, searchable history, level colouring, a histogram — for any *.log on disk. It can also stream Docker container logs alongside your files when you want both in one place.

Features

  • Live tail of local log files
  • Full-history search with highlighting
  • Time histogram & level colouring
  • Optional Docker container logs
  • Embedded UI — one static binary
  • No Go, Node or Docker to run
  • macOS, Linux, Windows
  • MIT licensed, open source

Get started

Option A — prebuilt binary (no Docker, no Go)

curl -fsSL https://raw.githubusercontent.com/lyminhtanh/dozzle-shim/main/install.sh | sh
dozzle-shim -logs ./logs -glob '*.log' -listen :8080
# open http://localhost:8080

Option B — Docker

docker run --rm -p 8080:8080 \
  -v "$PWD/logs":/logs:ro \
  -v /var/run/docker.sock:/var/run/docker.sock:ro \
  --group-add 0 \
  ghcr.io/lyminhtanh/dozzle-shim -logs /logs -glob '*.log' \
  -docker unix:///var/run/docker.sock

The -docker / socket mount is optional — drop it for file logs only. See the README for all flags.

FAQ

What is dozzle-shim?

A small Go program that serves Dozzle's unmodified web UI and feeds it by tailing your local log files, so you can view plain *.log files in a modern browser UI with live tail, full-history search, highlighting and a histogram — without Docker.

How is it different from Dozzle?

Dozzle reads logs from the Docker API. dozzle-shim reads plain files on disk and impersonates the slice of Dozzle's API its UI needs, so you get the same UI for services that log to files. It can optionally also stream Docker container logs alongside the files.

Does it need Docker or Go?

No. The prebuilt binaries for macOS, Linux and Windows are self-contained (the UI is embedded), so you need neither Go nor Docker. A Docker image is also available if you prefer docker run.
